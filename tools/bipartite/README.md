# Bipartite graph generators

    Used to observe chnages in modularity after edges removal.
    More detailed description in each file.


    We assume that the vertices in each partition are represented as separate columns.
    There are edges only between the columns.

    Files:
        - bip1.cpp -> complete bipartite graphs. Clusters divide vertices horizontally.
        - bip2.cpp -> nearly (edges removal) complete bipartite graphs. Clusters divide vertices
                      horizontally. We can decide about cluster size (for P.txt).
        - bip3.cpp -> nearly (edges removal) complete bipartite graphs. Clusters divide vertices
                      horizontally.
